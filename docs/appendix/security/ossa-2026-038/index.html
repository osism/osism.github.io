OSSA-2026-038: Multiple SSRF vulnerabilities in Glance web-download and HTTP image APIs

PropertyValue
Date2026-09-03
CVE[CVE-2026-71196, CVE-2026-71197, CVE-2026-71198
SeverityHigh
Affected ProjectGlance
ReporterSergey Kanibor (Luntry), Sami Yessou (switch.ch), Abhishek Kekane (Red Hat)

Summary​

The web-download import method ships with insecure default filtering that permits authenticated users to fetch arbitrary internal URLs, including cloud metadata endpoints. The URI validator does not perform DNS resolution before applying host filters, enabling bypass via attacker-controlled domains and DNS rebinding attacks. The HTTP image location API lacks host filtering entirely when the HTTP store is enabled, and fetched content is stored as image data accessible for download, converting blind SSRF into full-read exfiltration.

Every OSISM deployment running an unpatched Glance version and using the web-download import method or HTTP image location APIs (enabled by default) is affected.

Upstream has not published a CVSS score for this issue. The severity rating above is OSISM's assessment: an attacker holding a delegated credential can turn it into persistent access that survives revocation of that credential, obtain roles beyond the delegation, and reach other projects of the credential owner.

Affected Versions​

The upstream advisory states the affected ranges as >=16.0.0 <30.2.1, >=31.0.0 <31.1.1, and >=32.0.0 <32.0.1, so the fixes are expected in Glance 30.2.1 (2025.1/Epoxy), 31.1.1 (2025.2/Flamingo) and 32.0.1 (2026.1/Gazpacho).

At the time of this advisory there is no fixed Glance release available upstream for any series. The upstream fixes are still under review on OpenDev and have not merged yet.

Caracal (2024.1) is unmaintained and Dalmatian (2024.2) reached end of life on 2026-04-29 upstream; neither will receive an official fixed release. The community is working on providing backports of the fixes for these branches, we will update this advisory once these are available.

For Epoxy (2025.1) and Flamingo (2025.2) OSISM already ships container images that carry the proposed upstream patches ahead of their official upstream release. The same patches are included for Gazpacho (2026.1), whose images will be published with the upcoming OSISM 11 release.

How to Check if You Are Affected​

Check the Running Glance Version​

docker exec glance_api pip show glance | grep ^Version

Because no fixed Glance release exists upstream yet, your deployment is affected unless you have deployed an OSISM container image that includes the patches (see Remediation).

Vulnerability Details​

Remediation​

For OSISM Releases​

Because no fixed Glance release is available upstream, OSISM provides the fix as downstream patches for the Glance container images via the following changes:

  • PR #789 — patches for 2025.1 (Epoxy), 2025.2 (Flamingo), and 2026.1 (Gazpacho)

Patched rolling images are available for 2025.1, and 2025.2.

A fix will be included in upcoming OSISM releases that ship the patched Glance container images. Consult the OSISM Release Notes for version information and availability.

The affected code runs in the Glance API service (glance_api container). Using rolling tags, override the Glance container image in environments/kolla/images.yml. With a stable OSISM release the Kolla images are pulled from the kolla/release/<openstack_version> namespace with pinned version tags (docker_namespace in environments/kolla/configuration.yml), whereas the rolling images live in the kolla namespace. The image parameters therefore have to be overridden together with the tag; the tag override alone would point at an image that does not exist:

environments/kolla/images.yml
glance_tag: "2025.1"  # or "2025.2", depending on your OpenStack release
glance_image: "registry.osism.tech/kolla/glance"

Replace registry.osism.tech if you pull the images from a mirror.
